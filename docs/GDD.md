# Game Design Document

## Nome do Jogo
Café Aurora

## Visão Geral
Café Aurora é um jogo de gerenciamento narrativo onde o jogador administra uma cafeteria tradicional.

## História
O jogador herda uma pequena cafeteria que pertencia à sua avó. O local perdeu popularidade e precisa ser revitalizado.

## Gênero

- Simulação
- Gerenciamento
- Narrativo

## Plataforma
PC

## Estilo Visual

- 2D ilustrado
- ambiente aconchegante
- iluminação quente
- cafeteria tradicional

## Gameplay

Fluxo principal:

1. Cliente entra
2. Cliente faz pedido
3. Jogador escolhe item
4. Sistema verifica pedido
5. Cliente reage
6. Jogador recebe dinheiro
