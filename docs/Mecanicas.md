# Mecânicas do Jogo

## Sistema de Atendimento

1. Cliente entra
2. Cliente faz pedido
3. Jogador escolhe item
4. Sistema verifica pedido
5. Cliente reage

## Sistema de Paciência

Tipos:

- baixa
- média
- alta

Se o cliente esperar muito, ele fica irritado.
