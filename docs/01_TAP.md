# Termo de Abertura do Projeto (TAP)

## Projeto
Café Aurora

## Descrição
Café Aurora é um jogo 2D de gerenciamento de cafeteria onde o jogador assume o papel de um barista responsável por atender clientes e administrar o estabelecimento.

## Objetivo
Desenvolver um jogo funcional utilizando Python como ferramenta de aprendizado prático de programação.

## Justificativa
O projeto permitirá aplicar conceitos fundamentais da linguagem Python em um ambiente interativo, envolvendo lógica, organização de sistemas e manipulação de dados.

## Escopo

O jogo terá:

- sistema de clientes
- sistema de pedidos
- interface gráfica
- progressão de dias
- sistema de reputação
- cardápio evolutivo

## Tecnologias

- Python
- biblioteca gráfica 2D
- assets visuais e sonoros

## Resultados Esperados

- jogo funcional
- aplicação prática de Python
- projeto completo documentado
